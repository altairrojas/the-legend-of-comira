# Cova — separate character

Cova is the **black/dark cat character**. Cova is not Comira, not a black version of Comira, not a skin, and not an alternate form.

All Cova references and future runtime assets must stay under Cova-specific folders and metadata.

Planned runtime root:

```text
public/assets/characters/cova/
```

Do not reuse Comira identity fields, story metadata, filenames, palette labels, or character IDs for Cova. A dedicated Cova asset specification is maintained separately from Comira.
