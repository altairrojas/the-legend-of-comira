# Koba — separate character

Koba is the **black cat character**. Koba is not Comira, not a black version of Comira, not a skin, and not an alternate form.

All Koba references and future runtime assets must stay under Koba-specific folders and metadata.

Planned runtime root:

```text
public/assets/characters/koba/
```

Do not reuse Comira identity fields, story metadata, filenames, palette labels, or character IDs for Koba. A dedicated Koba asset specification will be created from Koba's own approved reference art.
